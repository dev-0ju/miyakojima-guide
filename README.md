# 미야코지마 가이드 🏝

일본 오키나와현 **미야코지마(宮古島)** 의 식당·관광지를 한 페이지로 정리한 가이드입니다.
해안선 지도가 파일 안에 내장돼 있어 **인터넷 없이도 열립니다.**

👉 **[가이드 열기](https://dev-0ju.github.io/miyakojima-guide/)**

### KML을 구글맵 앱에 넣는 법
1. PC에서 [google.com/mymaps](https://www.google.com/mymaps) → 로그인 → **새 지도 만들기**
2. 레이어의 **가져오기** → `map.kml` 업로드 → 저장
3. 폰 **구글맵 앱 → 저장됨 → 지도** 에서 열립니다

## 표기 규칙

- 🔴 반드시 지켜야 할 제약 (휴무 · 현금만 · 예약 필수)
- 🟢 유리한 조건 (24시간 · 무료 · 숙박자 할인)
- ⭐ 그 집의 대표 메뉴
- 마커 **테두리가 점선** = 주소의 동(字) 기준 **근사 위치**
  (일본 소규모 식당은 지도 데이터에 등록돼 있지 않은 경우가 많습니다. 정확한 위치는 구글맵 링크로 확인하세요.)
