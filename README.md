# 미야코지마 가이드 🏝

일본 오키나와현 **미야코지마(宮古島)** 의 식당·관광지를 한 페이지로 정리한 가이드입니다.
해안선 지도가 파일 안에 내장돼 있어 **인터넷 없이도 열립니다.**

👉 **[가이드 열기](https://dev-0ju.github.io/miyakojima-guide/)**

## 무엇이 들어 있나

| | 내용 |
|---|---|
| 🗺 **인터랙티브 지도** | 73개 지점을 구역별로 표시 · 마커 옆 이름 표시 · 드래그/핀치 확대 · 외부 리소스 0개 |
| 🔍 **검색 · 필터** | 가게명·메뉴로 검색 · 구역별/식당·관광 필터가 지도와 목록에 동시 적용 |
| 📱 **모바일 최적화** | 카드형 레이아웃 · 바텀시트 상세 · 가로 스크롤 없음 |
| 🍽 **식당 53곳** | 무엇을 파는지 · 대표 메뉴 · 가격 · 영업시간·휴무 · 예약 방법 · 구글맵 링크 |
| 📍 **관광지·거점 20곳** | 어떤 곳인지 · 볼거리 포인트 · 시설 정보 · 구글맵 링크 |

모든 지점에 **한글명과 일본어 정식명칭**을 함께 적었습니다. 구글맵 링크는 일본어명으로 검색되게 해두어 현지에서 바로 길찾기가 됩니다.

## 구역 구분

- **리조트 내 (시기라)** — 시기라 세븐마일즈 리조트 안의 식당 17곳
- **시내 (히라라)** — 번화가 니시자토·시모자토 일대
- **동부 (城辺)** · **남부 (上野)** · **이라부·시모지** · **마트·도시락**

## 표기 규칙

- 🔴 반드시 지켜야 할 제약 (휴무 · 현금만 · 예약 필수)
- 🟢 유리한 조건 (24시간 · 무료 · 숙박자 할인)
- ⭐ 그 집의 대표 메뉴
- 마커 **테두리가 점선** = 주소의 동(字) 기준 **근사 위치**
  (일본 소규모 식당은 지도 데이터에 등록돼 있지 않은 경우가 많습니다. 정확한 위치는 구글맵 링크로 확인하세요.)
